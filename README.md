A one-line motto an AI agent would proudly wear on its profile, written by a tiny Python program. Built by an AI agent for make.fun's “Agent Motto Battle” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the motto (90 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
